
# Portfólio - Fábio Becker

## Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica do curso Técnico em Informática do Senac. O objetivo é apresentar minha trajetória, conhecimentos, habilidades e projetos desenvolvidos durante minha formação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- LocalStorage
- EmailJS

## Estrutura do projeto

- `index.html`: página principal do portfólio.
- `css/`: arquivos de estilos.
- `img/`: imagens utilizadas no site e nos projetos.
- `js/script.js`: funcionalidades JavaScript, formulário de contato e painel administrativo.

## Projetos apresentados

### PãoTech

Sistema desenvolvido para uma padaria, com funcionalidades relacionadas ao cadastro de clientes, entregadores e gerenciamento de pedidos.

Repositório: https://github.com/Joaquimbreis/Paotech

### Portal Helpdesk

Sistema acadêmico de gerenciamento de chamados de suporte técnico, com funcionalidades de cadastro, consulta, atualização e exclusão de solicitações.

Tecnologias utilizadas: Python, Streamlit, SQLite e MySQL.

## Formulário de contato

O formulário permite que visitantes enviem mensagens pelo portfólio.

As mensagens são armazenadas no LocalStorage do navegador e também enviadas para o e-mail configurado por meio do EmailJS.

## Painel administrativo

O painel administrativo permite visualizar, editar e excluir mensagens armazenadas no navegador.

Para acessar o painel:

1. Abra o portfólio no navegador.
2. Pressione `Ctrl + Shift + A`.
3. O painel será exibido na página.

Na primeira utilização, são criadas 20 mensagens de teste no LocalStorage.

**Observação:** o painel é uma demonstração acadêmica e não possui autenticação segura para uso em produção.

## Responsividade

O projeto utiliza Bootstrap e CSS para adaptar a página a diferentes tamanhos de tela, como computadores, tablets e celulares.
